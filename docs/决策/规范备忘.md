## 毫米波时间戳使用规范（2026-08-13 澄清）

`sub-XXX_mmwave_timestamps.csv` 无表头三列：**帧号, DLL 时间戳, Python 时间戳**，每帧一行、一一对应、数据无缺失。

| 列 | 含义 | 间隔实测（sub-004） | 用途 |
|----|------|---------------------|------|
| 第 2 列 DLL 时间戳 | 固件逐帧打的硬件接收时刻 | 中位 10.0ms，std 1.28ms，干净稳定 | **帧内时间轴**（频谱、STFT、帧率换算） |
| 第 3 列 Python 时间戳 | Python 回调处理时刻 | std 96ms，含 3 秒级跳变 | **跨模态对齐**（与行为数据同源时钟） |

规则：
- 帧内分析（FFT/滤波/帧率）用第 2 列 DLL 时间戳，或直接等间隔假设（两者等价）
- 跨模态对齐（毫米波 ↔ 行为/NIR/RGB）用第 3 列 Python 时间戳，与 master_timeline 的 unix_ms 同源
- 禁止用第 3 列做帧内时间轴（抖动大），禁止用第 2 列做跨模态对齐（与行为时钟不同源）

## 脚本命名规范（2026-08-14 起）

- 新脚本一律 `{功能}_{对象}_{MMDD}.py`（MMDD 为创建日期，如 `validate_external_gold_0814.py`）
- 旧脚本保持原名不动（跨脚本 import 链与 git 历史延续），仅废弃时移 `archive_历史版本/`
- 脚本索引统一维护在 `docs/手册/脚本索引.md`（活跃/归档两部分），新增脚本必须同步登记；scripts/ 目录内不放 README（文档统一在 docs/）
- 版本主线（process_vital_signs_vN.py）沿用 vN 后缀，不适用日期规则

## Git 提交规范（参照 FocusWave，2026-08-10）

- **版本发布提交**：message 以版本号开头，格式 `v{版本} — {主题}：{具体改动}`（中文），并同步打 tag `v{版本}`，与 `CHANGELOG.md` 对应
  - 示例：`v9 — 谐波抑制主线：能量门定位 + 相位方差判别 + iirnotch 陷波（0807 迭代）` → `git tag v9`
- **常规提交**：Conventional Commits 类型前缀 + 简洁描述（英文或中文），聚焦"改了什么 + 为什么"
  - `feat:` 新功能 / `fix:` 修复 / `docs:` 文档 / `refactor:` 重构 / `clean:` 清理 / `chore:` 杂务
  - 示例：`fix: 段参考修正误判倍频（v1.3）`、`docs: 更新 CHANGELOG v9`
- **提交粒度**：一次逻辑改动一个 commit，不混改；换版本思路时先提交再改，不覆盖
- **禁止提交**：`output/` 产物、原始数据（npz/bin）、`__pycache__/`（.gitignore 已管）
- **不修改一敏的代码**：需要时引用，不直接改她的版本

## 目录命名

- 用编号+描述：`01_DebugTool/` `02_SART-30s/`，不用 `data_v1/` `src-v2_bp/` 这种容易混淆的名字
- 算法版本用 `v1/` `v2/` 不用 `bp/` `vmd/`
- 输出按原始数据分组而非算法版本分组，方便跨算法对比

## 文档规范

- `README.md`：目录结构 + 用法 + FAQ + 依赖，不写版本历史
- `CHANGELOG.md`：算法版本演进 + 数据对应表 + 按日期修改记录（2026-08-10 起替代版本说明.md）
- `图表索引.md`：每个图表必须有生成脚本、数据来源、日期
- 图表统一放 `output/figures/`，生成脚本放 `scripts/figures/`
- 文档放 `docs/`，不叫 `参考/`

## 代码规范

- 分析脚本（process）和图表脚本（gen_plots）分开，不混写
- 不修改一敏的代码，缺了找她要
- 一次性脚本用完即删（batch_run_all）

## 图表规范（2026-08-14 用户定）

- **所有图必须带图例**：图内涉及多种颜色/线型/标记含义时，必须加 legend 说明（如效应量颜色分级、均值线与基线虚线、散点类别）
- **空类别必须标注**：分类图（如探针 4 分类对比）中无数据的类别必须标 "n=0"，防止误读为空白/图 bug
- **标签偏斜要在图中可见**：标签分布偏斜（如全专注）时图要呈现偏斜本身，不能画成空白
