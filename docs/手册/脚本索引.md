# 脚本索引（scripts/）

> 命名规范（2026-08-14 起）：新脚本一律 `{功能}_{对象}_{MMDD}.py`；旧脚本保持原名；废弃脚本移 `scripts/archive_历史版本/` 对应分类子目录。
