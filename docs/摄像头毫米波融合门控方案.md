# 摄像头-毫米波融合门控方案

> 基于 2026-08-11 预实验实测（5/5 被试全显著, 预实验最强一致发现）。
> 脚本: `scripts/experiment_video_motion.py`；完整实验记录: `docs/优化决策记录.md` 实验 15-24。

## 一、核心发现

NIR/RGB 摄像头检测到的**运动量**（帧差能量）是毫米波数据质量的有效前置预测器：

| 被试 | ok 窗运动量 | 非 ok 窗 | p | Cohen's d |
|------|-----------|---------|-----|-----------|
| 003 | 5.59 | 8.33 | 0.006 | -0.52 |
| 004 | 4.96 | 8.88 | <0.001 | -0.92 |
| 005 | 3.52 | 7.31 | <0.001 | -1.19 |
| 006 | 8.76 | 12.69 | 0.023 | -0.58 |
| 007 | 1.93 | 5.06 | 0.009 | -0.88 |

- 运动量→非 ok 预测 **AUC = 0.69**
- **P90 阈值**（运动量 > 全部窗的 90 分位）标记的窗: 76% 为非 ok（精确率）, 误伤 ok 仅 4.5%
- NIR 与 RGB 都有效（d=-0.88 / -0.72）, NIR 略优（1080p vs 720p）
- 时间级耦合: 003 运动量单调上升（3.8→8.6）与质量下降（100%→44%）同步

## 二、运动量提取方法（参数固定）

```
NIR 视频 (30fps) → 每 30 帧取 1 帧 → 灰度 → 12.5% 缩放 (1080p→135x240)
→ 帧差绝对值均值 = 运动量 (1Hz) → 5s 滑动平均平滑
```

## 三、融合门控流程（正式实验集成）

```
摄像头运动量序列 (1Hz)                   毫米波 npz 分片
        │                                        │
        ▼                                        ▼
  窗内运动量均值 (>P90 → 标伪影)          SNR/IBI 质量门
        │                                        │
        └──────────┬─────────────────────────────┘
                   ▼
        联合可信窗 = 非伪影 且 SNR≥3dB 且 IBI≥0.8
```

1. **运动量前置门**（低成本, 实时可做）: 运动量 > P90 的 30s 窗直接标记伪影
2. **毫米波质量门**: 其余窗走 SNR/IBI 判定（现有 assess_preexp_quality）
3. P90 阈值按被试内分布计算（个体运动基线差异大, 005 均值 5.8 vs 007 2.8）

## 三.5、适用边界（重要）

- 上述 5/5 显著基于信号强度足够的被试（ok 比例 31-76%）
- **极弱信号被试（001 型: ok 比例 <20%, 单强反射无冗余）关系反向**（001: ok 窗运动量反而更高, d=+0.79）——其失败主因是信号弱, 运动量门不适用
- 落地前置条件: 先按毫米波信号强度基线（如 ok 比例 >30%）判断是否启用运动量门

## 四、限制与注意

- AUC 0.69: 运动量非唯一失败因素（定位竞争同样贡献）, 是**辅助前置门**而非替代
- ok 窗内运动量分层对 HR 无附加区分（ok 窗已足够干净, 无需窗内细化）
- 阈值 P90 的精确率/误伤率随被试不同有波动, 正式实验建议先标定
- 004 视频 65 分钟未随毫米波截断——正式实验需同步采集停止时间

## 五、对正式实验的意义

1. **数据质量的第一道门**: 运动量高时段可直接标记（甚至实时）, 减少无效分析
2. **伪影解释**: 运动量解释部分毫米波失败——实验记录可补充"运动时段"标注
3. **采集端反馈**: 运动量实时监控可提醒被试减少动作（提高整体质量）
