## 1. 总裁决

本轮结果接受为北京行为线的第一批正式结果。70 个可审计 session、46 个重复参与者、59,080 个 trial 和 1,400 个 Probe 已形成可复用的正式行为时间轴。

本轮不再新增身份、程序版本或时间线审计。北京行为线已经从“数据整理阶段”进入“结果分析阶段”。

## 2. 已可进入正式结果部分的内容

### 2.1 任务推进的时间趋势

前序正式模型显示：

- trial error 随 block 内进度上升，当前原始 `p=.028`；
- `probe_response=1` 的概率随 block 内进度下降，当前原始 `p=.004`；
- log RT 未见明显时间趋势；
- B1/B2 与进度的交互未见明显证据。

在 BB Probe mapping 已通过的前提下，`probe_response=1` 可在正式文字中解释为“完全任务聚焦”。但 `2/3/4` 仍不能整体命名为“走神”。

最终正文显著性措辞必须使用预先计划的 BH-FDR 校正后结果；若校正后结论改变，以校正结果为准。

### 2.2 B1 late → B2 early 恢复比较

本轮计划比较未观察到明确恢复效应：错误率、RT 中位数、RT SD 和完全任务聚焦比例的差异均未达到当前证据标准。

正式允许表述：

> 在预定义的 B1 最后 20% 与 B2 最前 20% 比较中，B2 起始阶段的错误率和 RT 波动方向上略有改善，完全任务聚焦比例也较高，但计划比较未提供明确统计证据支持稳定恢复效应。

禁止表述：

- “休息没有作用”；
- “休息导致恢复”；
- “第二阶段和第一阶段没有区别”。

## 3. Probe 前 10/20/30 秒结果目前属于什么

当前交接中的 10/20/30 秒表主要是所有 Probe 合并后的总体均值：

- 10 s：错误率 .049，RT 中位数 318.5 ms，RT SD 69.1 ms；
- 20 s：错误率 .053，RT 中位数 316.1 ms，RT SD 79.9 ms；
- 30 s：错误率 .051，RT 中位数 312.6 ms，RT SD 84.1 ms。

这些结果可以描述“Probe 前行为总体尺度”，但**还不能单独支持‘不同注意状态在 Probe 前已有行为分化’**，因为尚未在交接中看到按 Probe 状态分组的正式比较。

这不是新的 blocker，也不需要新 audit。直接复用现有 `probe_event_level_behavior.csv` / `preprobe_window_trajectories.csv`，在同一 70-session / 46-participant 数据上完成即可。

建议作为同一 RUN 的补充结果：

1. 比较 `probe_response=1` 与 `2/3/4` 在 10/20/30 s 的 error、RT median、RT SD；
2. 参与者重复测量结构保持不变；
3. 三个窗口全部报告，不挑窗口；
4. 同一指标的 10/20/30 s 作为一个预定义比较家族做校正；
5. 可附四类 `1/2/3/4` 的描述图，但不因结果重新定义主终点。

这一步应与传感器接入并行或先快速完成，不允许因此重新开启身份或时间线工作。

## 4. 下一阶段：把传感器挂到已经完成的北京时间轴

现在批准进入北京多模态事件分析准备。核心原则是：**沿用当前 70 个正式 session 的 participant/session/probe/time 体系，不建立第二套身份或第二套 Probe 表。**

### 4.1 NIR

先在现有可用 session/subset 上建立与这 1,400 个 Probe 的确定对应，优先分析参与者内变化：

- Probe 前 pupil level / variability；
- stage 与 time-on-task；
- 参与者内中心化；
- 如数据质量允许，再区分慢变水平与短时事件变化。

不得通过翻转 AUC 重新定义性能。

### 4.2 毫米波

先接入当前已可解释为非生理的动态/质量特征，例如：

- phase / micromotion；
- respiration candidate；
- target/coverage/QC；
- Probe 前 10/20/30 s 的变化与波动。

在 firmware / Tx / memory mapping / ECG逐搏验证未完成前，不把 cardiac candidate 写成 HRV 或正式心脏指标。

### 4.3 比较顺序

多模态事件分析优先回答：

`时间/阶段 → 行为 → +毫米波 → +NIR`

重点不是立即追求最高分类分数，而是判断：在已经知道任务时间结构和行为变化后，毫米波或 NIR 是否还有稳定的额外信息。

## 5. 下一轮建议只保留两个实际产出

1. `BEIJING_PREPROBE_STATE_CONTRAST_V1`：在现有 1,400 Probe 上完成按 Probe 状态分组的 10/20/30 s 行为比较和校正，直接补齐当前行为结果最后一块。
2. `BEIJING_MULTIMODAL_EVENT_ALIGNMENT_V1`：只在当前 70-session 正式时间轴上接入现有 radar/NIR 资产，输出实际可覆盖的 participant/session/probe 数和第一批事件轨迹；不得新建身份体系，不得重新跑旧 audit。

ECG/HRV 继续作为独立生理验证线推进，但不阻塞北京 radar/NIR 的非生理事件分析。

## 6. 对用户可直接说明的当前结论

北京行为数据现在已经支持一个清晰的初步图景：随着任务推进，完全任务聚焦报告减少，同时错误率出现上升迹象；平均反应时本身没有明显线性变化。休息后各指标方向上有一定改善，但当前预定义比较没有提供明确恢复效应证据。下一步是在相同时间轴上检验行为在不同 Probe 状态前是否已经分化，以及毫米波和 NIR 是否能提供行为和时间之外的额外信息。
