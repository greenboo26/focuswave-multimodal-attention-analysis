# GPT 裁决：北京传感器增量基线与下一步停止规则

日期：2026-08-25
依据 commit：`4f5fc6aa903f605cbb00b9300b92c81632dbaac3`
状态：`ACCEPTED_AS_FAIR_MINIMUM_INCREMENTAL_BASELINE`

## 1. 本轮结果接受范围

接受本轮为北京 70-session 行为时间轴上的第一版公平传感器增量基线。

本轮复用了既有身份映射、行为 Probe 事件表、NIR 表和毫米波已有汇总特征，没有重新恢复身份或重新扫描时间线。模型比较均在各自同一批 Probe 上将“行为基础模型”与“行为 + 传感器模型”比较，因此不把模态覆盖差异误当成增量。

当前结果：

- 毫米波子集：行为基础模型 ROC-AUC = .639；行为 + 毫米波 = .616；ΔAUC = −.023。
- NIR ≥80% 子集：行为基础模型 ROC-AUC = .604；行为 + NIR = .554；ΔAUC = −.050。
- NIR + 毫米波共同子集：行为基础模型 ROC-AUC = .597；行为 + NIR + 毫米波 = .529；ΔAUC = −.069。

因此当前可以写：

> 在严格同样本比较、参与者留一交叉验证和当前低复杂度汇总特征下，毫米波与近红外尚未显示出超越任务进度、区组和 Probe 前行为特征的增量预测证据。

不得写成“毫米波无效”“NIR 无效”或“多模态无效”。

## 2. 为什么这一结果仍然有价值

这轮已经解决了三个关键方法问题：

1. 同一个真实参与者不会同时进入训练和测试；
2. 每个传感器模型都与同一批 Probe 上的行为基础模型公平比较；
3. 传感器没有因为覆盖样本不同而获得不公平优势。

因此这是一条真正可复现的最低基线，不再只是接入测试。

## 3. 当前解释边界

毫米波目前使用的是已有汇总特征，包括呼吸候选、微动/相位和质量指标；NIR 使用的是已有瞳孔汇总指标。它们尚未完整展开为 Probe 前 10/20/30 秒的动态变化表示。

NIR 高质量子集只有 13 个重复参与者，统计稳定性有限。毫米波覆盖较大（46 个重复参与者），但当前结果仍只针对这一版特征表示。

233 个 NIR+毫米波共同 Probe 上的状态分组比较未发现稳定差异，可以作为探索性补充结果，不宜据此作模态无效结论。

## 4. 下一步只批准一轮“动态增量 V2”

为了避免无止境调特征，只批准一次预先限定的动态扩展，不进行大规模模型搜索。

### 毫米波动态特征

按 Probe 前 10/20/30 秒分别计算并固定报告：

- 微动/相位水平及变化率；
- 呼吸候选水平及变化率；
- 目标质量/覆盖及变化；
- 窗口内稳定性与短时波动。

不把任何未验证心脏候选命名为 HRV。

### NIR 动态特征

按 Probe 前 10/20/30 秒分别计算并固定报告：

- 瞳孔中位水平；
- 瞳孔变化率；
- 窗口内波动；
- 在可用数据上优先加入参与者内基线化/中心化版本。

三个窗口全部报告，不依据结果挑选最好窗口。

### 比较顺序

固定比较：

1. 时间/区组；
2. 时间/区组 + 行为；
3. 时间/区组 + 行为 + 单传感器动态；
4. 在严格共同 Probe 上再比较行为 + NIR + 毫米波动态。

仍使用真实参与者分组的交叉验证，同样本比较。

## 5. 停止规则

若动态增量 V2 仍未在同样本比较中显示稳定正增量，则停止继续对当前未验证汇总/动态特征做无止境调参或复杂模型搜索。

之后毫米波主线转向：

`公开 VS_DATASET Radar–ECG → 逐搏验证 → 心搏间期验证 → HRV 指标验证 → 将经过验证的生理指标重新接回北京 Probe 时间轴`

这是下一阶段毫米波最有科学价值的路线。

NIR 若动态 V2 仍无增量，则保留为探索性/辅助模态，不优先投入复杂深度模型。

## 6. 当前三条活跃主线

1. 北京行为：正式结果已成立，进入结果整理与报告。
2. 北京传感器：仅再做一次预先限定的 10/20/30 秒动态增量 V2。
3. ECG/HRV：VS_DATASET 完整包下载完成后立即恢复冻结的逐搏/IBI/HRV 外部验证。

不得新增身份审计、北京时间线审计或重新计算已完成的 C2 基线，除非出现新的直接矛盾证据。
