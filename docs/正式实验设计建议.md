# 正式实验设计建议（基于预实验全部分析）

> 2026-08-11 凌晨自主分析后整合。所有结论出处: `docs/优化决策记录.md`（31 项实验）。

## 一、预实验核心结论（设计依据）

1. **8 被试质量全景**: 004-007 可信（93-100%），000/003 部分可信（47%/46%），001/002 不可信（0%）——**可用被试率 6/8**
2. **生理×行为无稳健相关**: 全被试相关/事件相关/非线性特征均不稳健——预实验数据层面不支持"毫米波区分注意力状态"
3. **自报-客观全面脱节**: 探针标签偏斜（003/006 全专注）+ 答卷自报（睡眠/不适/专注力）与客观指标无一致
4. **行为指标污染**: 刺激序列有规律（柠檬后必出苹果），被试找规律策略 → RT 全局加速（007 313→177ms）——行为指标不纯净
5. **摄像头-毫米波融合（最强发现）**: 运动量×质量门 6/6 被试显著（d 中位 -0.90）

## 二、正式实验设计修改建议

### 1. 刺激序列（最优先）
- **修复 NoGo 位置规律**（004/005/006/007 全部发现规律）——随机化 no-go 或至少打乱间隔
- 决策点: 保留规律（走神生态）vs 随机化（行为纯净）——建议随机化 + 语义化判断（SART 原型, 走神率 20-40% 有文献保障）
- 若保留规律: 行为指标改用 RT 变异系数（RT-CV）/错误前 RT 加速（Oops 机制）, 不用错误率

### 2. 探针设计
- 增加探针间隔（Seli 2013: 间隔越长走神报告越多）——预实验 100s 间隔偏短, 建议 2-3 分钟
- 明确"刚才"定义（5/7 被试理解=整个间隔）——指导语强化或做多窗长敏感性
- 考虑增加"有意/无意走神"区分（Martínez-Pérez 2023）
- 走神/空白解离假设: 走神 HRV 高 vs 空白心率低（Corcoran 2025）——标签多样后优先验证

### 3. 数据采集
- **同步停止**: 004 视频 65min 未随毫米波截断——三模态同步停止
- **摆位**: 延续 0.5m 距离 + 波束走廊净空（0810 重测清单）
- **运动控制**: 视频实时运动量监控提醒被试（融合门控的采集端应用）
- **ECG 金标准**（建议）: 期望 IBI 误差 8-20ms（Gao 2025 基准）

### 4. 分析管线（v1.5 + 融合门控）
```
摄像头运动量门（motion_gate.py, P90 标伪影）
    → 毫米波质量门（SNR/IBI）
    → 联合可信窗
    → HR/BR/HRV 提取（含 SampEn/DFA）
    → 事件相关（错误事件锚点, 按键对照）+ 探针窗
    → 统计（个体标准化, 混合模型）
```

### 5. 样本量
- 被试内窗级相关: 8-10 有效被试（×45 窗）可检测 r≥0.25
- 个体差异: 30 被试（先验证生理变异存在）
- 按 1/3 冗余招募（可用率 6/8）
