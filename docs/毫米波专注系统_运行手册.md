# FocusWave 毫米波专注状态研究系统运行手册

## 1. 系统边界

本系统是研究型系统，不是医学诊断工具。所有可用窗口必须由行为时间戳定义，实验开始前、实验结束后、练习、休息和清理阶段不得进入模型。

系统分为四种模式：

1. 生理质量模式：输出心率、呼吸率质量和探索性 HRV。
2. 个体化毫米波模式：使用被试前半段标签校准，后半段独立评分。
3. 行为辅助多模态模式：在毫米波和 RGB/NIR 代理上加入探针前 60 秒 SART 行为统计。
4. 视觉探索模式：RGB 人脸/运动代理和 NIR 瞳孔代理，仅用于研究，不是默认输入。

默认个体化特征不包含毫米波 RMSSD/SDNN。HRV 只能显式使用探索模式，不能作为当前系统的正式专注依据。


## 4. 导出个体化模型

行为辅助模式示例：

```powershell
.\.venv\Scripts\python.exe scripts/personalized_temporal_runtime.py `
  --mmwave output\E_Data_FAST\focus_discrimination_augmented.csv `
  --crossmodal output\E_Data_FAST\crossmodal_features_all.csv `
  --behavior output\E_Data_FAST\behavior_probe_windows.csv `
  --behavior-assisted --expanded-vitals `
  --model-dir output\E_Data_FAST\personalized_models_validated `
  --output output\E_Data_FAST\personalized_temporal_runtime_behavior.json
```

模型只使用前半段校准标签拟合。没有至少两类校准标签的被试不会被强行拟合。

## 5. 对新窗口评分

```powershell
.\.venv\Scripts\python.exe scripts/score_personalized_models.py `
  --features output\E_Data_FAST\focus_discrimination_augmented.csv `
  --crossmodal output\E_Data_FAST\crossmodal_features_all.csv `
  --behavior output\E_Data_FAST\behavior_probe_windows.csv `
  --models output\E_Data_FAST\personalized_models_validated `
  --mode mmwave_rgb_nir_behavior `
  --output output\E_Data_FAST\personalized_scores_validated_behavior.json
```

输出字段包括：

- `probability`：研究性专注概率；
- `decision`：`research_focused`、`research_nonfocused` 或 `indeterminate`；
- `phase`：校准段或独立测试段；
- `reason`：质量失败、缺少模型或特征缺失原因。

`indeterminate` 是有效输出，不应改写成专注或非专注。

## 6. 当前参照结论

- 毫米波心率课程估计对 ECG 的 MAE 为 4.59 bpm，可用于研究性心率趋势。
- 毫米波呼吸率加入低频半频候选修正后，对呼吸带的 MAE 为 3.51 次/分；该结果来自 5 名被试、100 个严格门控窗口，仍属于研究性候选方法，需要独立队列复核。
- 毫米波 RMSSD 对 ECG 的 MAE 为 262.64 ms，当前不进入默认专注模型。
- 主数据纯毫米波跨被试专注识别接近随机。
- 个体化行为辅助模式有探索性信号，但不代表纯毫米波性能。
