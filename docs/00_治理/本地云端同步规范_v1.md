# 算法仓库本地—云端同步规范 v1

适用仓库：`greenboo26/focuswave-multimodal-attention-analysis`。

## 固定身份

- canonical remote: `https://github.com/greenboo26/focuswave-multimodal-attention-analysis.git`
- canonical integration branch: `main`
- `master` 是并行历史分支；不得将其误当作当前集成入口，也不得因文件整理自动合并两者。

## 分支与路径

1. 有现成授权分支时优先复用，不为临时分析或文件整理新建分支。
2. 一个分支只能有一个活动 checkout；多个 checkout 必须由 `git worktree list` 登记。
3. 远端已删除的本地分支保留其提交和证据，但取消失效 upstream，标记为 local-only；未经确认不得删除。
4. 活动 worktree 不得用普通文件操作移动；历史 worktree 只能用 `git worktree move` 归档。

## 同步与验收

1. 先 fetch，再分别比较本地 HEAD、远端 HEAD、upstream、ahead/behind 和工作树状态。
2. 常规同步只允许 fast-forward；分叉、脏工作树和大文件/模型变更必须暂停并报告。
3. 禁止 force push、hard reset、clean 或覆盖未提交用户修改来制造同步成功。
4. 推送后重新读取远端 commit SHA，并记录仓库、分支、commit、路径和验证结果。
5. 原始数据、视频、大型输出、缓存、虚拟环境、模型运行文件和认证材料不进入 Git。
