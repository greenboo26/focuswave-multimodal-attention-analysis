## 一、预实验核心结论（设计依据）

> 分析集 **003-010 共 8 名**（001/002 摆位失误、000 练习效应剔除，2026-08-13 用户定）。

1. **质量全景**: 8 名被试可信窗 100%（SPC 判据修复后）
2. **生理×行为无稳健相关**: 相关/事件相关/非线性均不稳健（2026-08-14 新算法重跑确认）——不支持"毫米波区分注意力状态"的简单对应
3. **自报-客观脱节**: 探针标签偏斜（003/006 全专注）+ 问卷自报与客观指标无一致
4. **预判策略污染行为指标**: 1494 个 correct 试次 RT<150ms（10.5%）为预判按键; 002/006/007 的 omission 90%+ 为预判性漏按; commission 中 23 个 RT<150 为预判性误按（8 人集口径）。**预判是规律任务的正常策略（SART: 规律→自动化→走神），数据分型处理，不改设计**
5. **规则切换成本**: 条件切换（NoGo 密度变化）真误按 +0.108（p=.012）; 同条件切换无效应（p=.676）——"休息打断"为规则切换适应假象，支持 BBBB
6. **Block 内轨迹**: 真误按段4-段1 -0.097（p=.004）改善 + 预判率 +0.053（p<.001）自动化增强——任务内是练习适应非疲劳
7. **休息效应**: 行为中性 + 生理无快速恢复 + 主观正面（9/10）→ 保留但**不宣称恢复作用**
8. **摄像头-毫米波融合（已降级）**: 8-11 的"运动量×质量门 6/6 显著"是旧质量门时代产物; SPC 修复后 8 人 636 窗非 ok 仅 17 个——运动量门无区分对象，砍掉（用户定），运动量保留为旁证

## 三、正式实验设计修改建议

### 1. 任务结构（BBB 方案，3 block 全 B 条件）

- **全 B 条件（BBB）消除规则切换成本**（真误按 +0.108 p=.012 为 ABCCBA 真实混杂）——支持林小宇方案的最强行为证据
- **单一条件不损失走神变异**: Martínez-Pérez 实证任务需求（NoGo 12% vs 23%）不影响走神率
- **序列改约束随机**: 消除预实验固定间隔导致的预判（10.5%）; 规则=每 27 试次≥3 NoGo+前 10 试次全 Go（Wiemers 2019 规则的密度保真版：26 窗数学下界 50 个与 NoGo=48/11.1% 冲突，27 窗=3/27=11.1% 精确相容，2026-08-14 实现）

### 2. 行为指标分型（预判处理, 数据分析层）

- **RT<150ms 判预判**, 排除出 RT 统计; **commission 分型**: 真误按（RT≥150）vs 预判性误按（RT<150）——事件相关锚点只用真误按; **omission** 以问卷第 4 题自报校准（90%+ 为预判性漏按）, 不单独做走神指标; **预判率 = 自动化指标**（Block 内上升 p<.001）

**预判判定依据**: ①生理学下限——视觉-运动延迟链极限 ~120-150ms（简单反应），SART 是选择反应（识别+判断+决策），<150ms 必为节奏预期而非刺激内容; ②文献判据——Cheyne 2009 用 RT<100ms 判预期反应（更严），通行阈值 100-150ms，150 为保守端; ③预实验三重旁证——预判率出现在固定间隔序列下（006 自报发现规律）、Block 内上升 p<.001（学习节奏过程）、剔除后"末尾变快"假象消失; ④灰区承认——150 非绝对分界，个别极快真实反应可能误判，但分型用于剔除分析，宁可剔错极少数也好过 10.5% 污染全部统计

### 3. 探针设计

- **频率**: 探针非反应性（Wiemers 2019, BF01≈2-3.7）可加密; 但越密报告率越低（Seli 2013）→ 取中定稿 30 个/人（1.11 个/min）
- **位置**: 不紧跟 NoGo（Oops 效应）; 唯一反例 McVay 紧跟 NoGo 是为了链接错误，与我们测状态目的不同
- **选项框架**: 4 选项 D2 定稿（依据 Robison: TRI 占 29%）; 三态分析硬约束——大脑空白生理方向与走神相反（Corcoran），合并会正负对消
- **参考时段措辞**: "此画面出现前一刻"（预实验 5/7 误解"刚才"）; 配套指导语明讲+探针.png 重制+程序同步
- **分析**: 探针后 1-2 试次修剪（中断效应）; 探针前 4-8 个 Go 试次 RTCV 预测走神（连续指标候选）
- **警觉度追加题（2026-08-14 新增）**: 题面参照 Corcoran"过去几个试次"——"在刚才这段任务里，你的警觉程度是？"（1 极度困倦 → 4 极度清醒）; 放注意状态题之后、每轮探针最后一问（Corcoran 同序）; 作答增加 ~2 秒
- **两题时间锚定不同的设计理由（有意为之，对标 Corcoran 原文）**: 注意状态题锚"此画面出现前一刻"（打断前瞬间），警觉度题锚"刚才这段任务"（过去几个试次）。三条理由: ①**状态时间属性不同**——注意状态（在想什么）是瞬时状态，走神几秒即切换，问"前一刻"才能抓到打断瞬间的思维内容; 警觉度（困倦）是分钟级慢变状态，问"前一刻"无意义，必须给时段评估; ②**与毫米波生理窗对齐**——分析取探针前 30-60s 生理窗，"过去几个试次"≈30-60s 与警觉度标签恰好对应（注意状态题锚"前一刻"与 30-60s 窗存在固有张力，是毫米波 HRV 长窗需求的方法学代价）; ③**规避探针唤醒效应**——探针出现本身使人精神一振，问"此刻困不困"会系统性高估清醒度，问"刚才那段"避开污染。配套要求: 指导语必须明讲两题时间范围差异（"第一题想打断前那一刻在想什么，第二题想刚才这一段整体状态"），已列入指导语重制事项
- **警觉度分析定位**: 协变量为主、第二标签为辅（注意状态与警觉度高度相关, Corcoran β=−0.87~−1.36, 不作独立维度解读）; 分布门控 V1+V2 < 5% 时降级为仅协变量; 分析方案见"6. 分析管线"警觉度段

### 4. 休息设计

- **保留 1-2 分钟、2 次**（BBB 三 block 间）; 功能=结构分段+体验维护，**不宣称恢复作用**（预实验数据+Corcoran 同定位）
- 文献先例: McVay 30s、VAGO/Corcoran 自定时——短休息不影响持续注意测量

**实验前静息 3 分钟基线（加入理由，2026-08-14）**:

- **文献对照**: 非所有生理研究都有——Corcoran 2025 无（直接进任务，分析=探针前窗的被试内状态对比，个体内设计自动控制基线）; Martínez-Pérez 2023 有（任务前后各 5min 静息 EEG，测 alpha 个体差异）; Bortolla 2021 有（10min 静息基线，正念前后 HRV 对比）; Task Force 1996 建议 5min 短时静息记录（通用规范非强制）
- **规律**: 有基线=跨个体比较或任务 vs 静息对比; 无基线=纯被试内状态对比
- **我们的理由（三条分析线中两条需要）**: ①主分析（探针标签状态对比，Corcoran 式）不依赖静息; ②四角度"任务 vs 休息"对比 + 个体标准化**需要静息参照**; ③休息效应"段内 RMSSD 起点"**需要静息提供进入实验的生理起点**
- **预实验依据**: rest_3min 独立采集质量 97%（全场最好），且 rest 段 RMSSD 个体差异 5.5 倍——个体标准化离不开基线参照
- **实施**: 坐姿确认页（"请确认是否调整好坐姿，即将开始静坐测试"，空格开始）后、Block1 前插入静息段（被试静坐 3 分钟倒计时自动结束，三模态同步采集; 预实验程序无此环节，已实现 v3.0.2）。不用游戏背景 321 倒计时——此时被试尚未学习任务规则与游戏情境

### 6. 分析管线（v1.7）

```
毫米波质量门（SPC 候选判据, 窗口级置信度 quality 三级）
    → 可信窗（行为时间轴截断强制; 摄像头运动量旁证）
    → HR/BR/HRV（30s 窗×15s 步进; IBI 连续性过滤 250ms; 30s 窗不做频域 LF/HF）
    → 行为分型（RT<150 预判 / 真误按 / 预判率）
    → 事件相关（真误按锚点）+ 探针窗（RTCV）
    → 统计（被试内 z 标准化, 混合模型）
```

窗口级置信度口径（110 人金标准验证）: quality 三级（时频差≤6/≤12 BPM → high/med/low, MAE 1.6/3.4/10.1）; HPS 谐波乘积谱选峰; 多 bin 共识投票; 只取 high/med 窗。

**警觉度分析方案（2026-08-14 新增）**:

1. **分布门控（分析前必做）**: V1-V4 占比 + 时间走势（预期随任务下降, Corcoran 时间效应显著）; V1+V2 < 5% → 警觉度降级为仅协变量（二分 V1-V2 vs V3-V4 备选）
2. **对标复现线（毫米波 → 警觉度）**: 混合模型 警觉度 ~ IBI 均值 + 探针序号 + (1|被试); 预期 IBI 长（心率慢）→ 低警觉（Corcoran β=−0.35, p<.001）——毫米波最可靠的输出就是心率, 此效应复现可能性最高; 4 点 Likert 主分析按连续处理（线性混合模型）, 敏感性分析用有序累积链接（ordinal::clmm）
3. **主分析协变量线（核心用途）**: 注意状态 ~ 毫米波特征 + 警觉度协变量 + (1|被试); 目的=分离"困倦"与"走神"对毫米波信号的贡献——若控制警觉度后某特征效应消失, 该特征实际在测唤醒度而非注意状态（对系统落地是重要诊断）; 反向模型同做（警觉度 ~ 毫米波, 控制注意状态）
4. **联合亚组（探索性, 样本量允许才做）**: 走神窗 216 个按警觉度二分后每组 ~100, 仅描述性对比; 不做 4×4 十六格交叉标签（稀疏）

### 7. 样本量

- 被试内窗级相关: 8-10 有效被试; 个体差异: 30 被试; 按 1/3 冗余招募
- 走神样本: 30 人×30 探针×80% 可信率 → 走神窗 ~216 个（30% 走神率口径）够主分析; 四态细分需 30 人
- **功效按保守值算**: Corcoran 的 ECG 效应 β=0.31（中等）会被毫米波 IBI 噪声（9.44-27.93ms vs ECG 亚毫秒）稀释, 预期 β<0.31

### 8. 对标文献关键含义

- **Corcoran 2025（效应基准）**: 检验逻辑=毫米波 HRV 能否复现"走神→HRV 升高 β=0.31"，及"低心率→低警觉 β=−0.35"（毫米波最易复现靶点, 心率是毫米波最可靠输出）; 窗长差异（他们 10s 贴标签, 我们 30-60s 堆心跳）是毫米波固有方法学局限, 写论文明示; 探针前窗分析沿用; 警觉度题设计对标（其 7-8 问仅 2 问进分析: 注意状态+警觉度, 其余未分析）
- **Martínez-Pérez 2023（结构对标）**: 18min/20 探针同款结构; 走神时间进程 0.34→0.47 支持 9min block; 行为错误≠走神状态（r 全不显著）——主分析以探针标签为锚, commission 为次级锚点; 指导语模板可抄（on-task 定义+IMW/UMW 实例）; 数据开放 OSF
- **毫米波 HRV 文献**: IBI 误差 9.44-27.93ms（mmCG/QDA-SSM/HEBR）; SDNN 误差 7.24ms << IBI 27.93ms——统计量对逐拍误差抵消, 窗口级 HRV 方向正确（不缩短窗长, 只说明测统计量比测逐拍可行）
- **其他**: Elkelani 走神率 34.3% 仅作统计数据点（0 引不引其声称）; 标签偏斜备选=拉长 ITI（走神研究常识+Martindale 2024, 非加长任务）; Cheyne RT<100ms 预期反应与预判分型同源
