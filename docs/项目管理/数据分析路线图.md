## 一、数据全景

SART 实验全程约 50 分钟（6 Block × 5 min + 5 × 3 min 休息），单被试约 17 GB。

| 设备 | 测什么 | 帧率 | 单被试量级 | 作用 |
|------|--------|:----:|:---------:|------|
| mmWave 雷达 (RS6240) | 心跳/呼吸 (IQ 复数信号) | ~99 Hz | ~4.1 GB | **模型核心输入** |
| NIR 瞳孔摄像头 | 瞳孔直径 | 30 fps | ~10 GB | 交叉验证 |
| RGB 摄像头 | 面部视频 | 30 fps | ~7.2 GB | 特征补充 + 质量标记 |
| SART 行为 | 反应时/正确率/漏报 | 事件型 | <1 MB | **标签来源** |
| 探针 | 主观专注评分 (1-5) | 每~30 trial | <1 MB | **标签来源** |

## 阶段一：数据整理与质量检查

**输入**：原始采集文件（每个被试一个文件夹）

```
sub-{编号}_/ses-SART/
├── mmwave/          ← .bin + .npz + _timestamps.csv + meta.json
├── nir/             ← .avi + _timestamps.csv
├── rgb/             ← .avi + _timestamps.csv
└── beh/             ← beh.csv + master_timeline.csv + events.csv
```

**检查项**：

| 检查 | 方法 | 合格标准 |
|------|------|---------|
| 文件完整性 | 各文件存在、可打开 | 全部通过 |
| mmWave 帧率 | CSV 时间戳差分 | ~97-100 fps，无跳帧 |
| NIR/RGB 帧率 | CSV 时间戳差分 | ~30 fps |
| 丢帧率 | CSV 中 status=dropped 比例 | < 1% |
| 时间戳单调性 | 检查严格递增 | 全部递增 |

**输出**：数据质量报告，标记不合格被试。

## 阶段二：单模态特征提取

### 2.1 毫米波 → 生理指标

代码：`08_算法/scripts/process_vital_signs_v2.py`

```
npz 加载 (n_frames × 256 × 8)
    ↓
range FFT (汉宁窗)
    ↓
选最佳通道 + 距离门 (SNR + 功率阈值)
    ↓
相位提取 + 解卷绕 → 胸壁位移
    ↓
VMD (K=4, α=1000) 分离呼吸/心跳
    ↓
峰值检测 (多阈值 + IBI 评分)
    ↓
计算 HR / BR / HRV 指标
```

**输出**：每个被试的生理指标时间序列文件 `{sub}_vital_signs.csv`

| unix_ms | hr | hrv_rmssd | hrv_sdnn | hrv_lf_hf | br | signal_quality |
|---------|----|-----------|----------|-----------|----|---------------|
| ... | 72.3 | 45.2 | 52.1 | 1.8 | 14.2 | 0.95 |

- 时间窗口：每 1 秒或 5 秒滑动
- `signal_quality`：信号质量指数（0-1），头动大的时段自动降低

### 2.2 NIR 瞳孔 → 瞳孔直径

需要由 NIR 团队完成。

**参考方法**：
- 现有开源瞳孔检测工具（如 Pupil Labs 的算法、OpenCV 阈值法）
- 或厂商提供的 SDK

**输出**：`{sub}_pupil.csv`

| unix_ms | pupil_diameter_mm | pupil_confidence |
|---------|------------------|-----------------|
| ... | 3.25 | 0.92 |

### 2.3 RGB 视频 → 辅助特征

现阶段主要用于：
- **头动检测**：帧间差分或 OpenCV 人脸关键点 → 头部位移量
- **眨眼检测**：眼部 ROI 的 EAR (Eye Aspect Ratio)
- **动作标记**：大幅运动时段 → 用于 mmWave 信号质量标记

**输出**：`{sub}_rgb_features.csv`

| unix_ms | head_movement_deg | blink_rate | motion_flag |
|---------|------------------|-----------|-------------|

### 2.4 SART + 探针 → 标签

行为数据本身就是标签，不需要额外特征提取。直接从 `beh.csv` 读取。

## 阶段三：对齐 + 构建特征矩阵 + 生成标签

### 3.1 时间对齐

所有设备使用同一台电脑的 `time.time()`，直接按 Unix 毫秒时间戳合并。

```python
import pandas as pd

# 加载各模态数据
vital = pd.read_csv('sub-001_vital_signs.csv')
pupil = pd.read_csv('sub-001_pupil.csv')
beh = pd.read_csv('sub-001_ses-SART_beh.csv')

# 最近邻匹配：每个 trial 找到对应的生理指标窗口
aligned = pd.merge_asof(
    beh.sort_values('absolute_onset_time'),
    vital.sort_values('unix_ms'),
    left_on='absolute_onset_time', right_on='unix_ms',
    direction='nearest', tolerance=500  # ±500ms
)
```

### 3.2 标签生成

使用多重标签来源，互相印证：

```
标签优先级：
  ① 探针评分 (1-5) → 二分：1-2=不专注, 4-5=专注
  ② 行为数据 → 漏报=不专注, 快速正确=专注
  ③ 事后报告 → 用于验证标签分布合理性

标签融合策略：
  - 探针和行为一致的 trial → 高置信度标签
  - 矛盾的 trial → 标记为"不确定"，可剔除或软标签
```

### 3.3 特征矩阵

最终用于建模的数据结构（一行 = 一个 trial 或一个时间窗口）：

| 特征类型 | 特征名 | 来源 |
|---------|--------|------|
| 生理 | hr, hrv_rmssd, hrv_sdnn, hrv_lf_hf, br | mmWave |
| 瞳孔 | pupil_diameter | NIR |
| 行为 | trial_num, block_num, stimulus_size | SART |
| 辅助 | head_movement, blink_rate, motion_flag | RGB |
| **标签** | **attentive** (0/1), **probe_score** (1-5), **label_confidence** | 行为+探针 |

## 阶段四：建模

### 4.1 建模思路

**目标**：从毫米波特征（HR/HRV/BR）预测专注状态。

**核心原则**：从最简单的方法开始，效果好就不加复杂度。

### 4.2 基线模型（最简单）

```python
from sklearn.linear_model import LogisticRegression

# 只使用毫米波特征
X = df[['hr', 'hrv_rmssd', 'br']]
y = df['attentive']

model = LogisticRegression()
model.fit(X, y)
```

如果基线准确率 > 75-80%，**就已经是一个可用的产品**。不需要深度学习。

### 4.3 模型复杂度递进

| 优先级 | 模型 | 适用场景 | 复杂度 |
|:----:|------|---------|:----:|
| 1 | 逻辑回归 | 线性可分 | ⭐ |
| 2 | 随机森林 | 有非线性关系，特征少 | ⭐⭐ |
| 3 | XGBoost / LightGBM | 大数据量，需要高精度 | ⭐⭐⭐ |
| 4 | LSTM / Transformer | 时序依赖强，前三个不够 | ⭐⭐⭐⭐⭐ |

### 4.4 特征工程方向

如果基线模型不够好，逐步增加特征：

- **时域 HRV**：SDNN, RMSSD, pNN50
- **频域 HRV**：LF/HF 比值（反映交感/副交感平衡）
- **呼吸特征**：呼吸频率、呼吸深度变异性
- **滑动窗口统计**：心率变化率（ΔHR）、HRV 变化趋势
- **跨模态补充**：加入瞳孔直径、眨眼频率

### 4.5 评估方法

| 方法 | 说明 |
|------|------|
| 留一被试交叉验证 (LOSO-CV) | 每次用一个被试做测试，其余训练。最严格 |
| 被试内 train/test split | 每个被试前 70% trial 训练，后 30% 测试 |
| 评估指标 | 准确率、精确率、召回率、F1、AUC-ROC |

**注意**：不能把同一个被试的数据随机分到 train 和 test——同一个人的相邻 trial 高度相关，会导致评估虚高。必须按被试分层或按时序分割。

## 阶段五：验证 + 部署

### 5.1 跨模态验证

用 NIR 瞳孔数据验证模型预测是否合理：

```
如果模型预测"不专注"→ 同时段的瞳孔是否显著放大？
→ 如果相关，说明模型学到了真实的生理-认知关联
```

### 5.2 部署

训练好的模型可以部署到实时系统：

```
毫米波 → IQ → 特征提取（轻量）→ 模型推理 → 专注度输出
```

模型本身非常轻量（逻辑回归就几个浮点数系数），甚至可以在嵌入式设备上运行。
