# 外部工程与 NIR 版本登记

主仓库 `mmwave-hrv-analysis` 不嵌套复制 NIR 工程的 Git 历史。NIR 工程在本机保留独立工作目录，主仓库只登记来源、提交版本和统一共享模型权重，避免同一套源码和模型出现两份无法区分的版本。

|---|---|---|---|
| `01_Attention-Analysis_nvidia-cuda/` | `https://github.com/kyandi233-dev/Attention-Analysis.git` | `324413c` | 有未提交的正式 NIR 运行脚本和批处理工具改动，未在本次主库提交中覆盖 |
| `external/attention-pipeline-v2/` | `https://github.com/kyandi233-dev/attention-pipeline-v2.git` | `825238c` | 有未提交的 NIR 运行脚本和采样配置改动，未在本次主库提交中覆盖 |

## 主库可直接获取的模型

同事只需克隆主库并执行 `git lfs pull`，即可从 `models/` 获取本次登记的 NIR、RITnet、人脸检测和 DeepVOG 权重。运行代码仍从对应 NIR 工程仓库获取，运行时配置必须记录所使用的工程提交版本。

## 未纳入主库的内容

- 两个 NIR 工程的虚拟环境、缓存、训练过程和原始数据；
- NIR 工程内部未提交改动；
- `runs/` 训练日志与重复模型副本。

如果要让主库同时固定 NIR 源码版本，应先在各自 NIR 仓库完成独立提交，再由主库增加子模块指针；本次不擅自推送或覆盖这两个外部仓库。
