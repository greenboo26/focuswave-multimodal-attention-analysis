> 目的：请毫米波雷达方向专家判断本数据**能否支撑 HRV（IBI 级）分析**，
> 以及**摆位应如何调整**。

## 数据概况

- RS6240 FMCW 雷达，SPI 传输，~99 fps，距离分辨率 3.75 cm/bin
- npz 为**已做距离 FFT 的距离域复数**：(1000 帧, 256 bin) × 8 通道，complex128
- 44 分钟静坐按键任务全程采集

## 核心疑问（详见诊断摘要）

1. 近场（0.1-0.3 m）强杂波（近场峰 0.14-0.28 vs 正常 0.07-0.12，最强时人体位置功率的 807 倍）是否致命？
2. 人体目标实测在 0.3-0.6 m（偏近），与近场杂波定位竞争，30s 窗可信率 43%
3. 定位到人体时 SNR 8-19 dB、IBI 有效率 100% → 信号本身可提取，问题集中在定位与摆位
