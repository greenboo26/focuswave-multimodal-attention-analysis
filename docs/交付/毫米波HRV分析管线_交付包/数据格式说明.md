# 毫米波数据格式说明（sub-000 预实验）

## 数据来源

- 雷达：RS6240 毫米波雷达（FMCW）
- 传输：SPI
- 场景：被试静坐执行按键任务
- 时长：约 44 分钟，261,000 帧

## 目录结构

```
sub-000_/mmwave/
├── sub-000_mmwave.datacube.bin     # SDK 原始 Datacube（2GB，分析不需要）
├── sub-000_mmwave.meta.json        # 采集元数据
├── sub-000_mmwave_timestamps.csv   # 逐帧时间戳
├── sub-000_mmwave_datacube.npz     # 第 1 片（帧 0-999）
└── sub-000_mmwave_datacube_part001.npz ~ part260.npz   # 第 2-261 片
```

## npz 分片格式（分析主用）

- 每片：`(1000, 256)` complex128 复数数组 × 8 个 key
- key：`tx0_rx0, tx0_rx1, tx0_rx2, tx0_rx3, tx1_rx0, tx1_rx1, tx1_rx2, tx1_rx3`（2TX×4RX 天线组合）
- 维度含义：
  - 轴 0 = 帧（时间），1000 帧/片 ≈ 10 秒（帧率 ~99 Hz）
  - 轴 1 = 距离 bin，256 点（**已做距离 FFT**，是距离域复数数据，不是原始 ADC）
- **距离分辨率：3.75 cm/bin**（带宽 8 GHz）；人体目标带约在 bin 8-45（0.3-1.7 m）
- 分片规则：主文件为第 1 片，`part001` 为第 2 片，依此类推；尾部空分片（<100 KB）是崩溃残留，可跳过
- 加载示例：

```python
import numpy as np
d = np.load('sub-000_mmwave_datacube.npz')
iq = np.stack([d[k] for k in sorted(d.keys())], axis=-1)  # (1000, 256, 8)
```

## timestamps.csv

每帧一行，三列，逗号分隔：

```
帧号, 设备时间(ms), Unix时间戳(ms)
13206, 1786327351258, 1786327351281
```

用途：将雷达帧与实验事件时间（unix_ms）对齐。

## meta.json 字段

| 字段 | 值 | 含义 |
|------|-----|------|
| frame_count | 261000 | 总帧数 |
| duration_s | 2632.81 | 总时长（秒） |
| fps | 99.1 | 帧率 |
| range_fft | 256 | 距离 FFT 点数 |
| doppler_fft | 32 | 多普勒 FFT 点数 |
| tx_ant / rx_ant | 2 / 4 | 发射/接收天线数 |

## 处理链路

```
npz 距离域复数
  → 通道/bin 定位（人体目标选择，距离门控）
  → 相位解包 + 去趋势（静态杂波对消）
  → 呼吸带估计 + 呼吸谐波陷波（iirnotch）
  → 心跳带带通（0.8-2.5 Hz）+ VMD 分离
  → 窄带逐拍检测 → IBI → HR / HRV（SDNN/RMSSD/LF/HF）
```

## 注意

- `.bin` 是原始底片，分析全部使用 npz，**bin 可以删除或存档，不影响分析**
- 数据为预实验采集，信号质量约 43% 的 30s 窗可信（近距杂波定位竞争问题），分析时以脚本输出的 quality 字段为准
