# 请先读

我们想请您看看这套方案大体有没有问题：

- **01 采集程序**：60GHz 雷达（RS6240）SPI 采集，~99fps，输出 256 距离 bin × 8 通道复数数据，存 npz + 时间戳
- **02 算法**：从雷达相位信号提取心率（HR）、呼吸率（BR）、心率变异性（RMSSD/SDNN），流程是相位解缠 → 呼吸带/心跳带滤波 → 谐波陷波 → 逐拍峰值 → IBI
- **03 结果示例**：4 名被试的质量评估（被试 A/B/C 可信窗 100%，被试 D 有部分呼吸谐波伪影窗已剔除），图中蓝点为可信窗

主要想确认三件事：
1. 采集配置（帧率、距离分辨率、天线）是否合理
2. 算法流程有没有明显的方法错误
3. 结果的可信度看起来如何
