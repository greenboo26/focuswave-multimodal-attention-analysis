# 毫米波文献关键图图谱（第一批）

**使用方式。** 这是“该画什么、为何画”的目录，不是要求复刻论文图片。页码为 PDF 页序。类型：处理前后、定位、phase、分离、频谱、ECG、HRV、流程/场景。所有图应来自 FocusWave 自己的毫米波数据，并标注 session、时间窗、单位、参数与排除规则。

## 本批视觉核验

已对关键页面进行了渲染视觉查看，而不只依赖文字抽取：Marnach PDF p.5（Figs. 7-9）、Yu PDF p.8（Figs. 2-4）、Hao A-VMD PDF p.6（Fig. 5）、Hao MRVS PDF p.6（Figs. 4-5）。它们实际呈现的共通表达是：成对前后图使用相同坐标，目标选择落在可见 range/phase 图上，分离步骤用波形或谱作为证据，而非只给最终 rate。
