# FocusWave 毫米波透明化审计：论文级诊断图规范（第一批）

**状态：设计规范，不是算法结果。** 本文件规定在既有 RS6240 处理链上应如何展示已有中间证据；不得据此新增算法、调参、重跑专注分类，亦不得使用 NIR 或 RGB 数据。任何图都必须明确它展示的是原始记录、现有派生量，还是质量控制（QC）诊断，不能把代理信号表述为已验证的生理结论。

## 1. 目的与适用边界

这套图的目标是让读者可直接判断：输入是否可追溯、目标是否被合理定位、每个既有处理步骤改变了什么、频率/相位证据是否支持解释、以及参考设备是否真的同步可用。它不能证明算法有效，也不能代替针对每个 session 的生理学验证。

三类优先级：

| 标记 | 含义 |
|---|---|
| **必需** | 正式透明化报告必须保留，或在所述分析链声称做过相应步骤时必须保留。 |
| **推荐** | 数据和既有输出允许时应提供，以提高可解释性。 |
| **条件适用** | 仅在相应原始量、处理步骤或参考通道实际存在且可审计时提供；不得用替代数据伪造。 |

## 2. 全部图的统一规则

- 每张图都写明 `subject/session`、记录起止时间或相对窗口、输入文件/派生文件标识、软件版本或代码提交、处理链版本，以及该图是 **原始 / 既有处理后 / QC**。
- 所有时间轴以秒（s）为单位；距离轴以米（m）；频率轴以赫兹（Hz）；相位以弧度（rad）；幅度必须写明线性单位、归一化方式或分贝（dB）参考值。未知单位必须标为“单位/标定未确认”，不可省略。
- 同一张“处理前—后”比较必须使用同一时间窗口、同一坐标范围、同一颜色范围（色标）和同一归一化规则；若出于可读性不得不改变，必须并排提供共同色标版本，并在图注解释改变的原因。
- 色图应使用感知均匀、色盲友好方案（如 viridis/cividis）；线图避免只靠红绿区分。禁止裁剪掉不利区段、只展示“漂亮窗口”、或以平滑替代原始曲线而不说明。
- 垂直标记、阴影窗和阈值线必须有图例或直接标签。每个阈值都要注明来源：既有代码常数、设备规格、预先定义 QC 规则，或仅用于可视化；绝不可暗示是数据驱动优化。
- 不确定、缺失、不同步、饱和或失败必须可见：用面板内的 `NOT AVAILABLE`/`SYNC FAILED`/`QC UNRESOLVED` 明示，而不是删去该面板。
- 图注必须区分“观测到的图形事实”与“解释”。例如“0.28 Hz 附近存在谱峰”是事实；“该峰为呼吸”只有在频带、同步参考与 QC 支持时才可写成候选解释。
- 正式报告至少选取一个通过输入完整性检查的真实 session 作为逐步示例；所有结论性汇总图同时报告分母、排除数和理由。单张成功案例不可代表全队列。

## 3. 八类标准诊断图

### A. Range–time / range–chirp 总览（必需）

| 项目 | 规范 |
|---|---|
| 科学问题 | 原始或既有距离处理后数据中，反射能量在时间/每个 chirp（调频连续波扫描）与距离上的分布如何？是否存在近距离强反射、漂移、掉帧或多目标？ |
| 输入与资格 | 需有 chirp/帧索引、range FFT（距离快速傅里叶变换）输出或能追溯的等价距离谱；若只有最终一维相位，不得补画为 range-time。 |
| 图型与轴 | 主图为二维热图：横轴时间（s，或明确为 chirp/帧编号）、纵轴距离（m）、色标为幅度/功率（写明单位或 dB 参考）。可附放大窗，但保留全距离总览。 |
| 必标注 | 天线/通道或合成方式、距离分辨率、最大显示距离、窗口、色标定义、已知静态物体/人体候选区、丢帧/无效段。 |
| 绝不可缺 | 距离轴、色标、数据层级（FFT 前/后）、全局视野与文件身份。 |
| 图注应陈述 | 能量位置和随时间变化的事实；近距离峰是否存在。不得把峰直接称为胸部，除非有独立定位依据。 |
| 失败/不可解释 | 距离标定未知、帧时基不明、输入已被不可追溯裁剪，或色标/通道不可恢复时，只能报告“range 证据不可审计”。 |

### B. DC 偏置 / 静态杂波处理前后（条件适用；若代码声称处理则必需）

| 项目 | 规范 |
|---|---|
| 科学问题 | 既有的直流（DC）偏置去除或静态杂波抑制具体移除了什么，是否同时损害目标附近的动态信息？ |
| 输入与资格 | 同一原始输入、同一通道/距离层、同一窗口的处理前与处理后数组；须能识别实际调用的既有函数和参数。不能以不同 session 或不同目标 bin 对比。 |
| 图型与轴 | 首选上下或左右并排的 range-time 热图；可加同一距离 bin 的时域剖面与距离剖面。坐标、色标、归一化完全一致。 |
| 必标注 | 处理名称、代码函数/版本、是否 DC、滑动背景/均值相减或其他静态杂波方法、时间窗、通道、共同色标。 |
| 绝不可缺 | 处理前图、处理后图、共同坐标和色标、处理说明。 |
| 图注应陈述 | 处理前后哪些稳定成分/低频基线发生变化，以及是否保留候选动态区；不把视觉上更干净等同于生理信号更准确。 |
| 失败/不可解释 | 无处理前数组、处理步骤无法从代码证实、或处理前后不是同一输入时，标记为“无法做因果前后比较”。 |

### C. 目标距离 bin / 通道选择（必需）

| 项目 | 规范 |
|---|---|
| 科学问题 | 最终使用的距离 bin 与接收通道为何被选中？近距离强反射、静态峰或多目标是否可能主导该选择？ |
| 输入与资格 | 需有候选距离 bin × 通道的既有评分/幅度/相干性，选择规则及距离门；若算法只隐式选择，必须以代码证据报告，不能反向杜撰评分。 |
| 图型与轴 | 距离剖面（横轴距离 m、纵轴选择指标）+ 通道比较；在 range-time 总览上叠加所有候选区、距离门和最终 bin。多 bin 可用热图。 |
| 必标注 | 全候选范围、距离门上下界及来源、最终 bin/距离、相邻候选、每通道结果、选择规则、选择发生在何个处理阶段。 |
| 绝不可缺 | 候选范围和距离门，不能只画最终 bin；用于选择的真实指标及其单位/定义；近距离区是否被纳入/排除。 |
| 图注应陈述 | 选择规则实际偏好的位置/通道，以及强反射是否与最终选择重合或相邻；不能将“最大幅度”自动解释为人体胸部。 |
| 失败/不可解释 | 无距离门、选择指标不可追溯、或近距离主峰未被显示时，标为高风险“target selection evidence incomplete”。 |

### D. 原始、展开、差分相位（条件适用；若后续用相位则必需）

| 项目 | 规范 |
|---|---|
| 科学问题 | 复数信号的原始相位、相位展开（unwrap）和相位差分各改变了什么？跳变、漂移及噪声是否可见？ |
| 输入与资格 | 同一最终/候选 bin、同一通道、同一窗口的复数 IQ（同相/正交）或可重建相位；必须证实实际是否使用 unwrap/difference。 |
| 图型与轴 | 三联共享时间轴线图：原始相位（rad）、展开相位（rad）、相邻帧差分相位（rad/帧或 rad/s，明确）。可附短窗放大。 |
| 必标注 | bin、距离、通道、相位公式、unwrap 方法、差分间隔、缺帧处理、滤波是否已发生。 |
| 绝不可缺 | 三层来源关系、单位和采样间隔；不得只显示视觉最平滑的最终相位。 |
| 图注应陈述 | 是否存在 ±π 跳变、长期漂移及差分后噪声变化；不把相位波动直接称为心搏。 |
| 失败/不可解释 | 没有复数输入、相位层已被覆盖、帧率或差分间隔未知时，说明相位链不可复核。 |

### E. 呼吸—心动分离（条件适用）

| 项目 | 规范 |
|---|---|
| 科学问题 | 既有分离/滤波步骤将相位或位移代理量分成哪些频带成分？两者是否仍有泄漏、瞬态或运动污染？ |
| 输入与资格 | 同一源序列和实际存在的既有带通、分解或抑谐波输出；必须列出滤波器/分解方法、通带、阶数/层数与边界策略。无此处理不得伪造“心动轨”。 |
| 图型与轴 | 共享时间轴的原始代理量、呼吸候选、心动候选三至四联线图；可在短窗叠加但需保留独立面板。 |
| 必标注 | 源信号、采样率、方法与全部关键参数、频带（Hz）、边缘无效区、运动/QC 标记、振幅单位/归一化规则。 |
| 绝不可缺 | 分离前输入、两个输出、实际频带/算法信息与同一时间基准。 |
| 图注应陈述 | 分离后各成分的时间结构及残留情况；只称“候选呼吸/候选心动成分”，除非有同步参考验证。 |
| 失败/不可解释 | 频带重叠、明显瞬态占据窗口、参数未保存、或源信号无可追溯性时，不能把该图用于生理结论。 |

### F. 含呼吸谐波和心率候选的功率谱密度（PSD）（必需，前提是已有频谱/可追溯序列）

| 项目 | 规范 |
|---|---|
| 科学问题 | 在明确窗口和分辨率内，候选呼吸、其二/三次谐波与候选心率峰如何相对出现？谐波混淆是否可见？ |
| 输入与资格 | 既有相位/分离输出及其实际 PSD；需窗长、采样率、窗函数、去趋势、谱估计方法和频率分辨率。未验证 HR 的峰只能叫候选。 |
| 图型与轴 | 单位一致的 PSD 曲线：横轴频率（Hz；可加每分钟次数 bpm 的上轴）、纵轴功率密度（单位²/Hz 或 dB/Hz，明确参考）。可在同窗对比源与分离输出。 |
| 必标注 | 分析窗、有效时长、频率分辨率、方法（如 Welch）、显示频带、BR（breathing rate，呼吸频率）候选、2×BR、3×BR、HR（heart rate，心率）候选及其数值/峰值规则。 |
| 绝不可缺 | BR、2×BR、3×BR 和 HR 候选全部标出；频带和分辨率；不要只留最终峰。 |
| 图注应陈述 | 峰的相对位置及 HR 候选是否落在呼吸谐波附近；不得把最高峰默认判为 HR。 |
| 失败/不可解释 | 频率分辨率不足以分开峰、BR 不可估、谐波与 HR 重合、窗时长/谱法未知或存在明显运动时，须明确“HR 峰不可判别”。 |

### G. Radar 与 ECG/RSP 同步标定（条件适用；若声称生理准确性则必需）

| 项目 | 规范 |
|---|---|
| 科学问题 | 雷达代理信号与 ECG（electrocardiogram，心电图）/RSP（respiration，呼吸参考）是否在同一可用时间基准下记录？可用于比较的窗口和局限是什么？ |
| 输入与资格 | 需原始/可追溯雷达时戳及 ECG/RSP 时戳，且已有同步映射、触发记录或明确的对齐规则。无同步证据不得画成验证图。 |
| 图型与轴 | 同一相对时间轴的多轨波形；另加全记录同步覆盖条。可显示滞后估计，但必须说明是设备触发还是事后对齐。 |
| 必标注 | 时间零点定义、各设备采样率、同步来源、偏移/漂移校正、可用窗口、缺失段、参考通道单位和雷达代理量。 |
| 绝不可缺 | 同步关系、窗口、时间基准、可用性状态；不可只放相关系数或覆盖后的短波形。 |
| 图注应陈述 | 可比较的时间段与对齐证据；ECG/RSP 参考是否完整、是否只适合作为 QC 或可进入定量校准。 |
| 失败/不可解释 | 时钟无映射、仅人工估计对齐、参考通道饱和/缺失、或窗口不重叠时，明确“不可做生理准确性标定”。 |

### H. Session 级 QC 总览（必需）

| 项目 | 规范 |
|---|---|
| 科学问题 | 每个 session 的输入完整性、距离/目标证据、运动/饱和、同步参考和各处理输出是否足以支持相应层级解释？ |
| 输入与资格 | 全部 session 的既有清单、处理日志和 QC 字段；缺字段应报告为未审计，不能默认通过。 |
| 图型与轴 | Session × QC 项目的矩阵/泳道图，或按参与者分组的时间线；色块为 PASS、PARTIAL、FAIL、UNRESOLVED/NOT AVAILABLE，不能用连续分数掩盖类别。 |
| 必标注 | 总分母、每类计数、session ID、QC 定义、排除理由、是否有 ECG/RSP、是否进入任何下游分析。 |
| 绝不可缺 | PASS/PARTIAL/FAIL/UNRESOLVED 的明确定义、缺失状态和分母；不得只公布通过 session。 |
| 图注应陈述 | 各证据层的覆盖与失败模式；区分“可作为算法输入”“可做代理信号诊断”“可做生理准确性验证”。 |
| 失败/不可解释 | session 身份无法统一、日志与数据不一致、或规则在看过结果后改动时，冻结为“QC 结论不可用”，待审计而非重新挑选。 |

## 4. 正式报告的最低保留集

1. A（range 总览）、C（目标选择）、F（PSD）与 H（session QC）为最低保留图组；若分析链含 DC/静态杂波处理，B 亦为最低保留。
2. 若分析链依赖相位，D 必须保留；若声称呼吸/心动分离，E 必须保留；若声称 ECG/RSP 支持的准确性或校准，G 必须保留。
3. 每类至少有一张完整真实 session 示例和对应的全队列 QC/分母证据。示例图不是成功率图的替代品，准确率图也不是中间证据的替代品。

## 5. 用户可直接判断的内容

- 是否真有完整距离数据、明确时间/距离单位，及是否存在近距离强反射。
- 最终目标 bin/通道是否在展示的候选范围和距离门内，而不是黑箱选择。
- 已声明的 DC/静态杂波或相位处理是否有同输入的前后证据。
- HR 候选是否可能只是 BR 的 2 倍或 3 倍谐波，谱分辨率是否足够。
- ECG/RSP 是否真的同步可用，而不是仅在图上看起来相似。
- 哪些 session 可用于输入/QC/代理信号诊断，哪些能用于生理准确性验证；所有缺失和未解决项是否被显式保留。
