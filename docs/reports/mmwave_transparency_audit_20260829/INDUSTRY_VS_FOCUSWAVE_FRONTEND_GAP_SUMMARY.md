# 第一批透明化审计汇总：行业规范与 FocusWave 前端实现

**日期：** 2026-08-29  
**状态：** PARTIAL（文献基准、可见代码与一个真实校准片段已核验；未开发、调参或重跑任何算法）

## 先给人话结论

这批工作把“应该看什么”和“目前实际做了什么”分开了。六篇论文共同支持的前半段逻辑是：从可追溯的复数雷达数据开始，完成距离变换或确认其来源，明确人体候选范围，再处理电子偏置/静态背景并以相位质量选择目标，才进入呼吸与心动分析。

FocusWave 当前可见链路确实读取了 8 通道复数 range cube，并有 0.30–1.50 m 的代码距离门与逐通道相位评分；但没有在可审计的采集/分析代码中找到显式 DC、IQ 校正、静态杂波、MTI 或背景相消。它也不是通过人体/胸部定位或波束形成选择目标。最重要的未闭环问题是距离：采集 metadata 的 37 mm 与分析默认的 0.08 m/bin 不一致，因此当前图上的“米”仍是代码坐标，不能当成已验证的物理距离。

这意味着“近距离强反射污染了选择”是**现实且高优先级的风险假设**，但本批没有把它说成已经发生的事实：目前只能确认代码没有可见的前端抑制和人体定位证据，也不能排除 SDK/固件内部有未公开处理。

## 现在不应做什么

- 不应据此新增滤波、MTI、VMD、波束形成或 target 规则。
- 不应重跑专注分类，或把单一校准片段外推到全队列。
- 不应以当前默认坐标声称受试者胸部距离，或将其作为生理验证证据。
