# 行为科学 v3 判退缺陷规范

本文件是网页修复的缺陷清单，不是 v2 结果解释，也不是正式报告章节。v2 结果、表、图和报告均已被监督判退；本分支只提供可公开的代码审阅材料。

## 判退对象与边界

被审阅对象是 `scripts/rejected_baselines/behavior/generate_behavior_science_analysis_v2_rejected_baseline.py`。它保留原失败脚本的统计实现，仓库副本仅将机器私有输入根目录改成环境变量/相对路径，并记录原始文件哈希。该脚本不得作为正式分析入口，也不得据其生成或发布 v2 结果。

## 必须在 v3 修复中解决的问题

1. 10、20、30 秒窗口对同一 probe 重叠取样，造成伪独立观测，并把窗口行数误标成独立样本量 `n`。
2. Q1 是名义类别，不能用有序或连续折线替代四类别模型。
3. probe 层只放 participant 随机截距，未处理 probe/session 的嵌套与重复观测依赖。
4. cycle、block、session、participant 层级不足，不能把不同层级的重复观测当作同一层级独立样本。
5. B1–B2 的 session 内配对与 participant 重复层级混淆，差值计算和不确定性估计不对应设计。
6. Q2 使用 `OrderedModel` 时没有重复测量层级或合理的 cluster 处理。
7. 森林图混合 probe、session、participant 等单位，并混用重复对比标签。
8. QC 把不可比的计数混在一起，未区分 probe、session 和参与者分析组的分母。
9. session/block 箱线图把嵌套结构画成伪比较，图形单位和推断单位不一致。
10. 错误轨迹未做被试内中心化，也未按事件/被试聚类处理。
11. 数学依赖相关被误作心理关系，未明确其仅是测量层或工程层关系。
12. 候选 0/1 矩阵没有证据权重、预先定义的选择规则和独立验证依据。
13. 报告逐图复述，没有把预先定义的问题、效应量、不确定性和限制组织成可审计论证。

## v3 通过条件

v3 只能以机器可读契约为执行边界，见 [`行为科学v3分析契约.json`](../../contracts/behavior/行为科学v3分析契约.json)。主 probe 表必须每个事件一行；10、20、30 秒只能作为明确分离的敏感性层。所有统计结果必须声明观测单位、聚类单位和分母，完整过程报告与正式报告章节分离。

本文件不冻结具体数据、匿名映射、效应数值或报告结论。真实身份映射只存在于受控数据区，不进入本仓库。
