# ADC 固件实测报告（2026-08-12，含多轮修正）

> **版本说明**：初版结论基于 bin146（5.4m）强信号分析，后经用户现场确认（5.4m 处无强反射物）+ 数据复核，判定该信号为**伪影**，基于它的相位/测角结论全部作废。本版为修正后最终结论。

## 背景

1D 距离域 8 通道相位不稳定（std 1.9-3.1 rad）阻碍角度测量，推测为固件侧 FFT 后处理引入或 chirp 相位抖动所致。编译 `mrs6240_p2512_adc.img`（RADAR_FRAMEWORK_ADC_MODE，输出原始时域采样），烧录实测验证：

1. 原始时域形态
2. 8 通道相位一致性
3. 帧率稳定性

| 设备 | RS6240 (2T4R), SPI (CH347, 60MHz) |

## 验证结果

### ① 原始时域形态 — 通过 ✅

- 数据形状 (n_frames, 256) complex128，幅度沿采样点均匀（峰/均值比 1.59）
- FFT 反演距离数学正确（bin×37mm）：0.7m 人体弱回波（bin17-21）、近场 bin9
- **HRV 可提取**：bin17-18 呼吸带 10-15%、心跳带 9.5-11%，与 1D 数据相当
- 结论：ADC 数据链路完整，PC 端自算距离谱 + HRV 可行

### ② bin146（5.4m）强峰 — 伪影嫌疑，未定论 ⚠️

- 幅度 ≈14（其他 bin 100+ 倍）、半功率宽度仅 1 bin（异常窄）
- 用户现场确认 5.4m 处无墙/无强反射物
- 判定方法：换环境/挪目标重采 30s，消失=环境反射，仍在=固件/系统伪影
- **影响**：远离 0.7m 目标，FFT 分离良好，不污染 HRV；但基于 bin146 的相位/测角分析**全部无效**

### ③ 通道相位与测角 — 最终结论（chirp 相位不连续）⚠️

**最终根因：chirp 间相位不连续（硬件特性，SDK 无配置可改）**

| 证据 | 数值 |
|------|------|
| 人体（bin17）通道间相位差逐帧跳变 | **0.60 rad/帧（随机）**，且 TX 组内（tx0_rx1/2/3）同样跳 0.79-1.59 rad |
| 泄漏（bin146）通道间相位差逐帧跳变 | 0.02 rad/帧（恒定） |
| SDK chirp 相位/PLL 配置项 | 不存在 |

机制：2T4R 8 通道全分时采样（每通道独立 chirp），PLL 每次重新锁相 → 各 chirp 起始相位随机 → 通道间相位相干被破坏 → 测角（相位差法/角度 FFT）从硬件层面不可行。
**文献依据**（TUDelft MIMO 相位相干 / MDPI FMCW / IEEE 77GHz）：DOA 要求虚拟阵元相位相干，chirp 间相位跳变直接破坏角度估计；TDMA MIMO 运动目标有相位迁移缺陷；校准路线（lens 标定）仅解决固定失配，救不了逐帧随机。

| 影响 | 结论 |
|------|------|
| 测角 | 判死（硬件限制） |
| HRV 呼吸 | 不受影响（调制 5-12 rad >> 随机相位 ~1 rad） |
| HRV 心跳 | 边缘（1.2 rad vs 1 rad 竞争） |
| 定位/质量（幅度域） | 无影响 |

附：绝对相位共模漂移 -1.56 rad/s（温漂）差分后抵消；"1D 模式相位不稳 1.9-3.1 rad"= 同一根因。

### ④ 帧率 — 通过 ✅

- 98.5 fps 稳定，空洞 17 帧 (0.1%)
- py_ts_ms 间隔分布（0-2ms 占 38%，其余 ~14ms）为 DLL 批量回调特征，非丢帧

## 修正记录（初版错误）

1. ~~"5.4m 强反射为墙"~~ → 用户确认 5.4m 无墙，判定为伪影
2. ~~"FFT 后 bin 相位 std 1.0-2.1 rad，chirp 相位抖动未根治"~~ → 基于伪影的分析，作废
3. ~~"测角精度 ±0.8-1.9°"~~ → 基于伪影（刚性）信号的测角结论，对真实人体不成立
4. ~~"已烧回 1D 固件"~~ → 事实错误，尚未烧回
5. ~~"bin146 旁瓣泄漏污染 0.7m"~~ → 置零实验证明完全独立（bin17 幅度 0.0411 不变），撤回
6. ~~"人体测角不可行（微动/SNR）"~~ → 根因实为 chirp 相位不连续（文献确认的硬件机制）

## 结论与建议

1. **ADC 模式可用**：时域形态正确、链路稳定、HRV 可提取（与 1D 相当）
2. **人体测角不可行**（1D/ADC 无差别）：限制来自 SNR 与人体微动，非固件问题
3. **下一步候选**（文献标准做法，未验证）：
   - 静态杂波去除（时间均值相减）后再测角/HRV
   - 8 通道角度 FFT（2D 阵列流形，RS6240 为 2D MIMO：RX 间距 2.45mm，TX 列 + RX 行）
   - bin146 伪影判定对照实验（换环境重采 30s）
4. 固件状态：ADC 固件仍在设备上，烧回 1D 由用户决定
