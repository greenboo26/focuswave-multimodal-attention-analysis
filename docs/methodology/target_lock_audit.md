# 毫米波目标锁定审计方法

## 目的

在计算 HR、BR 或 HRV 之前，先判断毫米波是否持续观测同一个近距离人体目标。人体目标锁定候选不等于胸腔微动已被证明，也不等于生理指标准确。

## 固定质量层级

```text
原始 NPZ
→ 全场距离初筛
→ 首/中/末分片时间稳定性
→ 多通道空间一致性
→ RGB 运动门控
→ HR/BR 复核
→ ECG支持下的逐搏/HRV验证
```

### 1. 全场距离初筛

`0.20–1.00 m` 只能作为候选筛查范围，不能作为充分条件。

### 2. 时间稳定性

对首、中、末分片分别计算距离峰。全场累计峰合理但分片峰漂移到远端或不合理距离的场次不能直接进入生理分析。

### 3. 多通道空间一致性

通道峰应围绕同一个空间峰聚集。当前探索性审计使用 8 通道支持数和 `±0.16 m`/`±0.24 m` 聚类范围，并记录分片内峰距范围。

### 4. RGB 运动门控

RGB 运动量只作为运动伪影候选门控，不作为胸腔锁定金标准。阈值必须记录版本、采样方式和有效覆盖率。

## 负例策略

明显距离漂移场次保留为算法开发负例，不因为不能进入正式生理解释而删除。
