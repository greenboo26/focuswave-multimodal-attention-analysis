# RGB 运动门控方法

本方法用于判断毫米波分析窗口是否可能受到明显身体/头部运动影响。

## 输入与对齐

- RGB 视频及逐帧 Unix 毫秒时间戳；
- 毫米波分片起止 Unix 毫秒时间戳；
- 使用绝对时间戳进行窗口匹配，不使用固定 NIR 偏移替代。

## 当前探索性实现

- 1 Hz 采样视频帧；
- 灰度图缩放至 12.5%；
- 相邻采样帧平均绝对差作为运动量；
- 5 秒平滑；
- 被试内平滑运动量 P90 作为初步标记阈值。

## 限制

P90 不是已验证的正式剔除阈值。视频开头、遮挡、曝光变化、解码异常都可能造成帧差升高，因此首分片标记必须人工或辅助规则复核。只有同时通过空间一致性和运动门控，才允许进入 HR/BR 复核；运动门控通过也不能证明 HRV 有效。
