## 一.5、2025-2026 HRV 算法前沿（2026-08-09 补充, DOI 已验证）

> 来源: WebSearch + CrossRef 验证; 全部纳入 Zotero 库 `毫米波HRV_6篇.ris`

| 文献 | 期刊 | 方法核心 | 精度（ECG 对照） | 与我们的关系 |
|------|------|----------|-----------------|--------------|
| **QDA-SSM** (Li/Zhou 2026) DOI: 10.1109/access.2026.3691396 | IEEE Access | 质量门控（幅度可靠性+相位连续性掩码）+ 状态空间模型 + 雷达-ECG 机电延迟建模 | 14 被试 56h 雷达-ECG, IBI-RMSE 优于学习基线 | 质量门控思路与我们 IBI CV 门控同方向, 更系统 |
| **HEBR** (Li 2026) DOI: 10.1109/jiot.2026.3661997 | IEEE IoTJ | 谐波感知时频集中增强 + 动态规划跟踪基波 + 谐波支撑集重建 | IBI 中位 27.9ms, **SDNN 误差 7.24ms**, F1 0.893 (11 人含 1 心脏病人) | **SDNN 误差 7.24ms 为毫米波 HRV 标杆**; 误差报告与我们指标对标 |
| **mmCG** (Zhao 2025) DOI: 10.1109/jiot.2025.3573511 | IEEE IoTJ | 心跳空间定位（方向性感知提 SNR）+ 动态峰值搜索（时间相关伪影抑制） | IBI 误差 9.44ms（-51.3%） | "心跳空间定位"= 选 bin 高级版, 回应 bin 之争 |
| **自适应模板匹配** (北航 2025) DOI: 10.1109/tim.2025.3545726 | IEEE TIM | 120GHz 窄波束透镜 + 个性化心跳模板匹配 | MAE 18ms, RMSE 24.4ms, 覆盖率 98.8%, 房颤病人临床测试 | 模板匹配做拍检测, 比峰值检测稳 |
| **Cui 2025** DOI: 10.3390/s25175607 | Sensors | 3D 目标定位（数字波束成形+MTI+DBSCAN 聚类）+ 二阶谱稀疏分离 | IBI 误差降 50%+ | 目标定位 = CFAR 类选 bin 完整实现 |
| **谐波放大法** (Iwata 2025) DOI: 10.1109/access.2025.3575932 | IEEE Access | 复信号二阶导绝对值放大心跳 + VMD + 拓扑法 IBI | 相关 +0.20, RMSE -23% (11 人) | 心跳增强思路可借鉴 |

**共同趋势**: ① 质量门控成标配（QDA-SSM 掩码、HEBR 谐波支撑集）; ② SDNN 精度标杆 7.24ms（HEBR）; ③ 选 bin → 空间定位升级（mmCG/Cui 波束成形+聚类）
