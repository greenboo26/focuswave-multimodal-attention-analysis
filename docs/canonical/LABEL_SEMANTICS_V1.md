# Canonical label semantics v1

This mapping is normative for retained reporting and code:

| code | canonical meaning |
|---|---|
| 1 | fully task-focused |
| 2 | experiment-related but not sorting-task-focused |
| 3 | task-unrelated thought |
| 4 | mind blank / no specific thought |

The binary endpoint is label 1 versus labels 2/3/4, described as fully task-focused versus other non-fully-task-focused states. Labels 2/3/4 are not a single mind-wandering construct.
